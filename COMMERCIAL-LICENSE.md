## When do you need a commercial license?

You need a commercial license if you want to:

- Offer JARVIS OS as a managed service (SaaS) without open-sourcing your modifications
- Embed JARVIS OS in a proprietary product
- Use JARVIS OS internally in a way that would trigger AGPL copyleft obligations
- Remove or hide the AGPL license headers

## When is the free AGPL license sufficient?

The free AGPL license covers:

- Running JARVIS OS on your own server for your own use
- Modifying the code and keeping it private (as long as you don't offer it as a service)
- Distributing modified versions under AGPL v3
- Using JARVIS OS in your own open-source projects
