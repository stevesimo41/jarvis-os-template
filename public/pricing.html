Questions

Can I really use the Community plan for free?
Yes. The full source code is on GitHub under the AGPL v3 license. Clone it, run it, modify it — forever. You just need your own server and LLM API key.
What's the difference between Community and Pro?
Community is self-hosted — you run it on your own machine. Pro is cloud-hosted — we run it for you, include an LLM, configure email, and keep it updated. You just log in and use it.
What do I get with Business?
We set everything up for you: target market, email templates in your voice, CRM connection, outreach cadence, and a 1-hour onboarding call. You go from zero to fully operational in one session.
What does the AGPL license mean?
You can use, modify, and self-host JARVIS OS freely. If you run it as a service for others, you must share your modifications. If you want to keep modifications private (e.g., for a commercial product), you need a commercial license — contact us.
Can I upgrade later?
Absolutely. Start with Community, and upgrade to Pro or Business whenever you're ready. Your data stays yours — we can migrate your pipeline.
Do you offer a free trial for Pro?
Yes — 14 days, no credit card required. Try it risk-free.
