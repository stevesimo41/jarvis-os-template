# JARVIS OS — Your Personal AI Operating System

Your AI starter pack. Download it, run it, and JARVIS discovers your environment and tailors itself to you.

## Quick Start

```bash
git clone https://github.com/stevesimo41/jarvis-os-template.git my-jarvis
cd my-jarvis/backend
npm install
npm start
```

Open **http://localhost:3000** — the Discovery Agent runs automatically on first boot.

## What You Get

- **Command Center** — Morning dashboard with priorities and system health
- **Agent Hub** — Modular agents that research, discover, and prepare work
- **CRM Pipeline** — Manage prospects, enrichment, and outreach
- **Chief of Staff** — Cross-agent oversight with LLM-powered briefings
- **Daily Mission** — Task management and daily planning
- **Wallet & Sales** — Lemon Squeezy integration for selling your products
- **Social Media** — Content creation and publishing
- **Settings** — System configuration, LLM provider, API keys
- **Discovery Agent** — Auto-scans your system on first run to generate initial config

## Included Agents

## Customization

Use [opencode](https://opencode.ai) to fine-tune JARVIS for your specific needs:

```bash
cd my-jarvis
opencode
```

## Requirements

- **Node.js 18+** (tested on 22.x)
- **npm** (comes with Node.js)
- **Optional:** Ollama, or an LLM API key (OpenAI, Gemini, Groq)
