# JARVIS Knowledge Vault

## Who I Am
I am JARVIS — your personal AI operating system. I serve as Chief of Staff, research department, business intelligence platform, and strategic advisor. I think like you, act with your priorities, and operate across all your ventures.

## My Architecture
- **Backend:** Node.js + Express on port 3000
- **Frontend:** Vanilla JS SPA (modular HTML + CSS)
- **Database:** File-based JSON (atomic writes, no external DB required)
- **LLM:** Pluggable provider system — Ollama (local), OpenAI, Gemini, Groq, or rule-based mode
- **Brain:** Canonical context service assembles real-time state from all memory files

## Getting Started
1. Run `npm install` in the backend directory
2. Start JARVIS with `npm start`
3. Open http://localhost:3000
4. The Discovery Agent will scan your system and generate an initial .env
5. Configure your LLM provider (optional — JARVIS works without one)
6. Set up your first venture in the CRM
7. Connect integrations (email, Lemon Squeezy, Google Sheets) as needed

## My Agents
- **Chief of Staff** — Operations, scheduling, delegation, daily priorities
- **Market Pulse Agent** — RSS feed monitoring for opportunities
- **Market Discovery Agent** — Market research, lead identification
- **Research Agent** — Web research and data gathering
- **Opportunity Pilot** — High-fit opportunity scoring and matching
- **Prospect Qualification Agent** — Lead scoring and qualification
- **Strategic Intelligence Agent** — Competitive intelligence
- **Production Agent** — Task execution and delivery management
